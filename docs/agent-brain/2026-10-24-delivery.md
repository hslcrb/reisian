# Reisian alpha — integrated delivery evidence

**Date:** 2026-10-24  
**Scope:** the integrated Electron + React/TypeScript visual website builder, original identity and open-source project foundation.  
**Status:** implementation and scoped verification complete; final publication and two-parent merge to `main` remain the integration owner's last steps at the time of this report.

This report records the integrated result. Earlier engine, desktop and identity handoffs describe their isolated branch states and intermediate limitations. Where they differ, the final evidence here applies to the integrated checkout; historical handoffs are retained to explain the work.

## What was delivered

Reisian is a local-first, visual-only editor. Authors can start from Atelier, Portfolio or a blank project; manage pages and section order; edit section text directly on the canvas; edit card/gallery items in the inspector; upload embedded raster images; adjust theme and section styles; choose scroll presets and procedural WebGL geometry; preview desktop/tablet/mobile widths; run authoring checks; undo/redo; save/open `.reisian` files; and export a standalone website ZIP.

The editor, preview and export share the page renderer. Exported HTML, CSS and JavaScript run without an account, Reisian backend, CDN or AI service. Raster images remain embedded. External links can leave the site when followed; remote image URLs and executable user code are rejected.

The desktop application uses isolated Electron main/preload/renderer boundaries, a narrow native bridge and validated file operations. Native open/save/export use dialogs; writes use a temporary sibling file before replacement. Imports and archives have explicit size/path limits. These controls are tested within the scope below and are not a claim that every possible malicious input has been proved safe.

Original identity assets include the folded R symbol, wordmarks, monochrome variants, app SVG, 512-pixel PNG and seven-size Windows ICO, palette and brand board. The repository includes MIT licensing, contribution/security/conduct documents and issue/PR templates. The README preserves “AI Native 시대에서 물고기보다 물고기를 잡는 낚시대로써” and the brand promise “당신의 감각이, 그대로 웹이 되는 곳.”

### Native test limits

Native dialog return values are supplied by the smoke harness, while the actual application IPC, filesystem operations, ZIP creation and isolation checks run. The tests cover project save/open, cancellation, invalid input/path rejection, archive contents, write failure reporting, denied navigation/remote requests and an actual software-rendered WebGL pixel. Native pickers have not received a manual usability review on each target OS.

The execution environment is a root-owned Linux container without a display. The explicitly requested smoke configuration was:

```sh
REISIAN_ELECTRON_NO_SANDBOX=1 REISIAN_ELECTRON_HEADLESS=1 REISIAN_ELECTRON_SOFTWARE_GL=1 npm run test:desktop
```

The packaged run additionally sets `REISIAN_ELECTRON_EXECUTABLE` to the packaged Linux executable. The no-sandbox switch belongs to this test invocation; the shipped application does not add it and keeps `contextIsolation: true`, `sandbox: true` and Node integration disabled. These runs verify configured preferences and functional behavior, **not Chromium OS sandbox enforcement inside this container**. Software WebGL success does not establish performance or driver compatibility on every GPU.

## Accessibility evidence and limits

The built-in authoring check identifies selected issues in page titles/descriptions, visible headings, image alternatives, link destinations/labels, solid-color contrast and motion review. It does not determine whether an alternative description is meaningful or whether every reading order is appropriate.

The browser suite runs axe with WCAG 2A, 2AA, 2.1AA and 2.2AA tags, excludes the canvas iframe, and asserts no **serious or critical** violations in the tested editor state. The engine handoff separately records **zero axe violations** for the default exported template fixture. These are different scopes. Neither result certifies the application, arbitrary author content or all interactive states as WCAG conformant. Human keyboard, assistive-technology, contrast-over-images and content review remain necessary.

Visible focus, semantic structure, alternatives to dragging, reduced-motion support and a motion pause control are part of the implementation. Final review also corrected low-contrast interface text and modal Escape handling.

## Review corrections included

- Flush active inline canvas text before save/export so the latest words are retained.
- Avoid a pending-edit timeout when saving from preview.
- Preserve the latest state during end-of-session autosave.
- Reject invalid or Windows-reserved page slugs without applying an invalid document.
- Generate noncolliding anchors when pages/sections are duplicated.
- Resolve and scroll to a contact fragment on another page during preview.
- Correct interface contrast and modal Escape behavior.
- Validate packaged dependencies and run the packaged executable, rather than treating a successful packaging command as sufficient evidence.

## Alpha boundaries

This is a usable early alpha, not parity with mature builders. It supports a constrained section model, preset motion and procedural 3D; there is no arbitrary DOM/code editor, complete timeline or 3D scene tool, hosted CMS, commerce, authentication, collaboration service or automatic updater. Individual card/gallery text is edited in the inspector rather than directly on the canvas. WebGL context restoration requires a page reload after context loss. The interface currently uses English copy; Unicode author content and bilingual documentation do not imply full UI localization.

Linux native and packaged execution were tested with the container limits above. Windows portable builds are unsigned cross-builds; Windows runtime behavior is untested. macOS was not built or signed. Autosave is not a backup; preserve separate `.reisian` files. Packaging and functional verification do not remove these limitations or constitute a general release-readiness guarantee.
