# Reisian roadmap / 앞으로의 방향

This roadmap describes direction, not promised release dates. The current alpha is a local-first, section-based visual editor. Read the [README](../README.md) for its supported workflow and limitations, and `docs/agent-brain/` for actual validation evidence.

## Make the foundation dependable

- Exercise native open/save/export and packaging on additional desktop operating systems.
- Establish signed distribution and an update strategy before promising an end-user release channel.
- Expand import/export regression cases, document schema migrations and improve recovery from corrupted or incompatible projects.
- Test keyboard and assistive-technology workflows with people using them; improve authoring guidance where automated checks cannot decide intent.
- Improve rendering consistency and performance on low-power graphics hardware, including reduced-motion and WebGL-unavailable paths.

## Give authors more range

- Additional original section patterns and starter sites with strong responsive defaults.
- More deliberate typography controls and a local asset-management workflow.
- Richer motion sequencing with readable controls and accessible defaults.
- More 3D composition options after reliable fallbacks, resource limits and controls are established.
- Better page navigation, metadata and publishing guidance while preserving portable static exports.

## Explore only with a clear user need

A reusable component system, richer content collections, optional publishing integrations and collaborative workflows need design work before implementation. AI assistance may help authors explore choices, but the core visual editor should remain usable without an AI subscription or network account.

Payments, authentication, a hosted CMS, a marketplace and arbitrary user-code execution are not commitments. Framer/Wix-style parity is not a release criterion for this alpha.

## Propose the next improvement

Open a feature request explaining what you are trying to create, where the current workflow gets in the way, and how the interaction could work with a keyboard. Prefer a small improvement that someone can use and verify. Accessibility, portability and clear ownership of project files are constraints throughout this roadmap.
