# Reisian Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development with independent worktrees; record findings in docs/agent-brain.

**Goal:** Deliver a usable visual Electron website builder with local project files and independent accessible site export.

**Architecture:** A typed JSON project feeds one renderer. The React editor manages history and visual controls; sandboxed Electron adds native dialogs and safe persistence. The exported runtime is self-contained.

**Tech Stack:** React, TypeScript, Vite, Electron, Vitest, Playwright, JSZip, procedural WebGL.

**Spec:** docs/superpowers/specs/2026-10-24-reisian-design.md

## Global Constraints
- No GitHub Workflows; all validation runs locally.
- All new branches start with chatgpt/; use hierarchical namespaces and integration leaves.
- All merge commits preserve two parents; each tiny English-prefix/Korean-message commit is immediately published.
- Visual-only editing; no account required; no remote dependency in exported sites.
- Do not claim comprehensive accessibility conformance or untested platform readiness.

## Review Focus
- Malformed/untrusted project imports must fail without losing the current document.
- Undo after editing/reordering and project switching must restore consistent page selection.
- Motion and WebGL unavailable/reduced-motion conditions retain all essential content.
- Exported paths and links remain safe and valid for multiple pages and embedded images.
- Native cancellation, write failure and untrusted renderer messages preserve the user's files and show actionable feedback.
