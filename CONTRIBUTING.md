# Contributing to Reisian / 기여 안내

Thank you for helping people create a web that feels like them. Small, well-explained improvements are welcome: bug fixes, keyboard usability, Korean and English copy, documentation, rendering, export reliability and tests.

Read the [contributor guide](docs/CONTRIBUTING.md) before making a change. It explains local setup, the visual-only product contract, verification and the branch/commit workflow. Follow the [community policy](CODE_OF_CONDUCT.md), and report sensitive vulnerabilities through the [security process](SECURITY.md).

작은 개선도 환영합니다. 변경을 시작하기 전에 [기여 가이드](docs/CONTRIBUTING.md)를 읽어 주세요. 접근성, 한국어 문구, 문서와 재현 가능한 버그 제보도 소중한 기여입니다.
